# Drill 14 · 새의 비행 애니메이션

기존 소년·잔디 장면 위에서 새 10마리가 세 줄로 비행합니다. 편대는 오른쪽과 왼쪽으로 6초씩 이동하며, 화면 가장자리에서 감속한 뒤 방향을 바꿉니다.

## VS Code에서 실행

VS Code로 `drill14` 폴더를 열고, 폴더 루트에서 터미널을 실행합니다. Python 3.13에서 확인했습니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

새는 실행하자마자 자동으로 비행합니다. 기존 소년은 좌우 방향키로 움직이고, 스페이스로 공을 던집니다. Esc 또는 창 닫기로 종료합니다.

## 구현 방식

- `bird_animation.py`는 `bird_animation.png`의 자세를 위쪽부터 5·5·4장 순서로 읽습니다. 각 프레임에서 눈을 기준으로 잡은 몸통 좌표를 기록해 날개가 바뀔 때 몸통의 기준 위치가 움직이지 않게 합니다.
- `bird.py`는 경과 시간으로 초당 2.4회의 날갯짓을 계산합니다. 왼쪽을 향할 때 스프라이트와 몸통의 가로 보정 방향을 함께 뒤집습니다.
- `bird_flock.py`는 10마리를 3·4·3의 대칭 편대에 배치하고 새마다 다른 날갯짓 시작점을 줍니다. 코사인 곡선으로 왕복 위치를 계산하고 사인 곡선을 더해 고도를 조금씩 바꿉니다. 편대의 폭과 가장 넓은 프레임을 기준으로 이동 끝점을 정해 화면 안에서 방향을 전환합니다.
- `play_mode.py`는 초기화할 때 편대를 기존 월드에 한 번 등록합니다. 기존 월드가 편대의 갱신, 그리기와 종료 정리를 담당합니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

14개 자세, 반전 시 몸통 기준점, 편대의 개체 수와 양쪽 화면 경계를 검사합니다. Windows의 pico2d 창에서 양쪽 방향의 렌더링, 기존 소년의 방향키 입력 및 Esc 종료도 확인했습니다.
